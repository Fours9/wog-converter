# WOG Converter

Конвертер локального кэша World of Guns для Windows. Восстанавливает внутренний бандл `.unity3d` из файла кэша `__data` или из файла `.bytes`, полученного через AssetRipper. Бандл можно открыть в AssetRipper и экспортировать игровую модель для Blender.

## Что нужно

- Windows и Python 3 с Tkinter. При установке Python включи **Add Python to PATH**. Проверено на Python 3.13. Сторонние пакеты Python не нужны.
- AssetRipper для экспорта из `.unity3d` и Blender для открытия `.glb`.
- Локальный файл модели. Ghidra, dnSpy и Il2CppDumper для обычного использования не нужны.

## Как пользоваться

1. Открой модель в World of Guns и дождись загрузки. Если модель уже есть в кэше, этот шаг можно пропустить.
2. Скачай или склонируй репозиторий и распакуй папку, если скачал ZIP. Держи `WOG Converter.cmd`, `WOG Converter.pyw` и `wog_cache_converter.py` рядом.
3. Запусти **WOG Converter.cmd** двойным щелчком.
4. Выбери запись из списка кэша. Если игра только что скачала модель, нажми **Обновить**. Через **Обзор…** также можно выбрать `__data` или `.bytes` вручную.
5. Укажи папку сохранения, оставь поле **Ключ** пустым и нажми **Конвертировать**. При успехе нажми **Открыть папку** и найди новый `.unity3d`. Исходные файлы сохраняются, а при совпадении имён программа добавляет к новому файлу числовой суффикс.

Путь к кэшу на Windows:

```text
%USERPROFILE%\AppData\LocalLow\Unity\Noble Empire_World of Guns\<имя_модели>\<идентификатор_версии>\__data
```

## Где искать GLB

1. В AssetRipper открой **File → Open File** и выбери восстановленный `.unity3d`.
2. Запусти **Export → Export Primary Content** и выбери папку выгрузки.
3. В папке выгрузки открой `Assets\objects\model_<имя_модели>\`. Ищи основной GLB. Его имя часто выглядит как `<имя_модели>_hd.glb`. Например, для Mossberg 500 путь проверен на реальной выгрузке:

   ```text
   <папка_экспорта>\Assets\objects\model_mossberg_500\mossberg_500_hd.glb
   ```

   Имена и структура папок могут отличаться. Если GLB несколько, начни с самого крупного файла с именем модели. Отдельные GLB в той же папке могут содержать детали, а PNG — текстуры.
4. В Blender выбери **File → Import → glTF 2.0 (.glb/.gltf)** и открой основной GLB. Чтобы проверить материалы, переключись в **Material Preview**.

## Совместимость

Автоподбор ключа проверен на кэше **Mossberg 500** и **M4 Carbine**. Программа проверяет распаковку внутреннего UnityFS перед сохранением. Поддержка других моделей зависит от формата их кэша. Если автоподбор не сработал и ключ известен, его можно ввести вручную как 32 шестнадцатеричных символа.

В репозитории только исходники конвертера и документация. Игровые файлы и выгрузки в комплект не входят.
